# Changelog

## Unreleased

- Renamed from `dissident` to TidyWin (`tidywin`).
- Public repository, licensed under GPL-3.0.
- Shortcuts through GitHub Pages: `irm androksi.github.io/tidywin/<name> | iex` for `windows`, `apps`, `chrome`, `brave` and `firefox`, plus `<name>-revert` to undo. Generated by `web/build.sh` in the `pages` workflow.
- Documentation in English.
- `docs/reinstall.md`: reinstalling Windows step by step, with the commands in order.
- Every script asks for the language when it starts: English (default) or Portuguese. `-Lang en` or `-Lang pt` skips the question.
- **Configure-Windows**: saves your answers and adds `-Check` (shortcut `windows-check`) to find and reapply what a Windows update brought back.
- **Clean-Windows** (shortcut `cleanup`): frees disk space item by item and shows how much was freed.
- **Configure-Dev** (shortcuts `dev` and `dev-revert`): editors, Git, SSH key for GitHub, signed commits, Windows Terminal with a Nerd Font, Developer Mode, languages and WSL.
- **Repair-Windows** (shortcut `repair`): DISM, sfc and an online disk check, with a restore point first.
- **Backup-Apps** (shortcuts `apps-export` and `apps-import`): saves the installed apps list and reinstalls it after formatting.
- **Backup-Drivers** (shortcuts `drivers-export` and `drivers-import`): pick the drivers to save before formatting (in use come checked) and install back only the ones Windows didn't bring back by itself.
- **Configure-Windows**: optional classic right-click menu on Windows 11, an option to block programs installed by the firmware (WPBT), and options for Snap windows, the Xbox apps, Recall, the Edge desktop shortcut, Num Lock at startup and Fast Startup.
- **Configure-Windows**: optional removal of the Snipping Tool, which also frees the Print Screen key for apps like ShareX.
- **Configure-Windows**: optional screen, sleep and hibernation times, plugged in and on battery.
- **Configure-Firefox**: removes the "Add to taskbar" and Picture-in-Picture buttons from the address bar, asks whether to keep page translation and, optionally, removes the Reader View icon.
- **Get-Wallpapers** (shortcut `wallpapers`): pick wallpapers from a list and download them, with a preview gallery in `docs/wallpapers.md` kept up to date by `tools/Update-WallpaperGallery.ps1`.
- **Configure-Apps**: adds Cloudflare One (WARP / 1.1.1.1), Unified Remote and the Visual C++ Redistributables (2015-2022 and 2005-2013, x64 + x86), 104 apps in total. One entry can install several packages.
- **Configure-Apps**: Firefox and Thunderbird follow the Windows display language instead of always installing Portuguese (Brazil).
- **Install-Fonts** (shortcuts `fonts` and `fonts-revert`): pick from 19 fonts (code, Nerd Fonts and text) and install them for every user from their official sources; the revert removes only what it installed.
- **Revert-Configure-Windows**: deletes only its own saved answers from `%ProgramData%\TidyWin`.

## v1.0.0 — 2026-10-10

First release.

- **Configure-Windows**: telemetry, suggestions, junk apps, OneDrive, Edge, Windows Security, theme, taskbar, File Explorer, everyday tweaks and DNS with DNS over HTTPS.
- **Revert-Configure-Windows**: undoes what Configure-Windows changed.
- **Configure-Apps**: 100 apps through WinGet, with search, per-category selection and interactive install.
- **Configure-Brave / Chrome / Firefox**: privacy policies, with `-Revert`.
