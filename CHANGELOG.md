# Changelog

## Unreleased

- Renamed from `dissident` to TidyWin (`tidywin`).
- Public repository, licensed under GPL-3.0.
- **TidyWin panel**: one command, `irm androksi.github.io/tidywin/run | iex`, opens a window with every option in a sidebar (set up, maintenance, formatting, undo). Each page says what the option does; the questions show as cards (choices, checklists with search, folders) and the progress as a live log, with Stop and Copy log. Light or dark like Windows, with its accent color. Generated by `web/build.sh` in the `pages` workflow.
- **Windows in the panel**: every option on one page, in tabs, each with what it does. Nothing comes selected and there is no "Default" option: only what you turn on or pick is applied. Review lists the changes before Apply. `-NoPrompt` is gone; `-Describe` and `-Answers` are how the panel talks to the script.
- **Install apps and Install fonts in the panel**: pages like Windows, nothing selected. Apps come in a tab per category, with a short description each and an Interactive box; fonts in one list. What is already installed is marked **Installed** in green.
- **Chrome, Brave and Firefox in the panel**: every policy group and every former question is a switch, all off at first; only what you turn on is applied.
- **Maintenance and Formatting in the panel**: every option opens straight on its options, like Windows, with no page before it and no questions. Check after an update lists what came back; Free up disk space has a switch per item with its size; Repair Windows a switch per step; Reset the network Quick or Full and an optional restart; Uninstall programs a searchable list and one switch for the leftovers: what is certainly theirs goes right away, what only might be is listed at the end to pick; Back up and Restore where to save, the app list and the drivers on one page. Nothing comes selected.
- **Terminal**: the terminal where you run the command shows the TidyWin logo and the Windows version while the panel is open, and says goodbye when it closes. No other window opens.
- **Browsers**: Chrome, Brave and Firefox on one page, a switch for each browser with its options under it; Review lists the changes by browser.
- **Undo in the panel**: Windows, Chrome, Brave, Firefox and fonts open a page instead of starting right away. One switch per subject, all off; the browsers and fonts show only what is on this PC. Only what you turn on is undone.
- **Site**: a landing page with the name and the command, nothing else to keep up to date; the documentation is on GitHub.
- **Wallpapers removed**: the option, the collection and its gallery.
- **PC report removed**.
- **Development removed**: the option, its undo and its page; developer apps stay in Install apps.
- Documentation in English.
- `docs/reinstall.md`: reinstalling Windows step by step, with the commands in order.
- English only: no language question and no `-Lang` parameter.
- **Configure-Windows**: saves your answers and adds `-Check` to find and reapply what a Windows update brought back.
- **Clean-Windows**: frees disk space item by item and shows how much was freed.
- **Repair-Windows**: DISM, sfc and an online disk check, with a restore point first.
- **Reset-Network**: quick (DNS/ARP caches and a new IP) or full (Winsock and TCP/IP) network reset with Windows' own commands, keeping DNS servers set by hand and DNS over HTTPS.
- **Backup-Apps**: saves the installed apps list and reinstalls it after formatting.
- **Backup-Drivers**: pick the drivers to save before formatting (in use come checked) and install back only the ones Windows didn't bring back by itself.
- **Configure-Windows**: optional classic right-click menu on Windows 11, an option to block programs installed by the firmware (WPBT), and options for Snap windows, the Xbox apps, Recall, the Edge desktop shortcut, Num Lock at startup and Fast Startup.
- **Configure-Windows**: optional removal of the Snipping Tool, which also frees the Print Screen key for apps like ShareX.
- **Configure-Windows**: optional screen, sleep and hibernation times, plugged in and on battery.
- **Configure-Windows**: removes LinkedIn with the preinstalled apps, and can unpin the ad shortcuts from Start (LinkedIn, Spotify, TikTok, Solitaire...) while keeping the rest of the pins.
- **Configure-Windows**: detailed log with one line per setting (`[OK]` changed, `[--]` already set), a final summary, and a log file on the Desktop with the answers and everything shown.
- **Configure-Windows**: one checklist of apps to remove, showing only the apps on the PC, instead of four yes/no questions; shorter, direct questions without parentheses; "Default" instead of "Keep as is".
- **Configure-Windows**: screen resolution, refresh rate and scale for each monitor, from the modes it supports, with the recommended and current ones marked; "Default" changes nothing, and a new resolution goes back by itself after 15 seconds unless Enter is pressed.
- **Configure-Firefox**: removes the "Add to taskbar" and Picture-in-Picture buttons from the address bar, asks whether to keep page translation and, optionally, removes the Reader View icon.
- **Uninstall-Apps**: pick programs and uninstall them with their official uninstaller, then delete the leftovers you confirm (folders and shortcuts to the Recycle Bin, registry keys and scheduled tasks backed up first).
- **Configure-Apps**: adds Cloudflare One (WARP / 1.1.1.1), Unified Remote and the Visual C++ Redistributables (2015-2022 and 2005-2013, x64 + x86), 104 apps in total. One entry can install several packages.
- **Configure-Apps**: adds Lenovo Vantage (Microsoft Store), 105 apps in total.
- **Configure-Apps**: Firefox and Thunderbird follow the Windows display language instead of always installing one fixed language.
- **Install-Fonts**: pick from 19 fonts (code, Nerd Fonts and text) and install them for every user from their official sources; the revert removes only what it installed.
- **Revert-Configure-Windows**: deletes only its own saved answers from `%ProgramData%\TidyWin`.

## v1.0.0 — 2026-10-10

First release.

- **Configure-Windows**: telemetry, suggestions, junk apps, OneDrive, Edge, Windows Security, theme, taskbar, File Explorer, everyday tweaks and DNS with DNS over HTTPS.
- **Revert-Configure-Windows**: undoes what Configure-Windows changed.
- **Configure-Apps**: 100 apps through WinGet, with search, per-category selection and interactive install.
- **Configure-Brave / Chrome / Firefox**: privacy policies, with `-Revert`.
